# Quickstart: Clickable Voting Banner

```bash
pnpm --dir votiy-web test
pnpm --dir votiy-web lint
pnpm --dir votiy-web build
```

1. Open public event while voting is open.
2. Confirm banner text and existing Vote button.
3. Activate banner by mouse and keyboard; confirm same access flow.
4. Verify code prompt and sign-in outcomes match Vote button.
5. Rapidly activate banner; confirm one request.
6. Verify visible focus and mobile readability.
7. Close voting; confirm banner disappears.
